## Vulcan (CricutVulcanDevice)
- main at 0x100005268: argv[1] == "-v" or "--version" -> sub_1000051b4 (print version), else sub_100004980 run loop.
- sub_100004980: fread 4 bytes from stdin (length, little-endian, signed 32), loop with 5 ms sleep (0x4c4b40 ns) until 4 bytes; then fread N bytes; parse (sub_1000dd7f4) as cricut.plugin_vulcan.proto.Request; dispatch on oneof; serialise Response (field 100 invalid_request on unknown = 0x64 seen in code); write 4-byte LE length + bytes to stdout with fwrite + fflush (pseudo lines 193-222).
- sub_10000ab34 = enumerate: calls sub_100009adc(ctx, "vulcan pod unit device", "", "", 0x1100, connection_type, cb). sub_100031d18 builds IOHIDManager matching dict with @"VendorID"/@"ProductID" (lines 27/40 of pseudo/vulcan-sub_100031d18.c).
- proto: FindDevices, GetPodInfo (activated flag, ERROR_DEVICE_AUTH_FAILED), UpdatePodFirmware, UploadMainUnitFirmware, ActivatePod (ACTIVATE/DEACTIVATE), GetDeviceErrors, SetSerialNumber. ConnectionType NONE/USB/BLUETOOTH/UNIT_DEVICE. Machine type enum in CricutDevice has VULCAN_MT / VULCAN_APP_MT next to ROOT_BEER (EasyPress family), PBUserSettings7 has Vulcan_120 / Vulcan_230 (mains voltage variants) => Vulcan is a heat-press class "pod + main unit" product, NOT the Maker 3.
- Linked: IOKit, CoreFoundation, libc++ only. No Bluetooth frameworks. Uses hidapi ("HIDAPI_%p", IOHIDDeviceGetService).
