# 34 Precision tools

**Wave 7. Depends on 22, 23, 21, 28. Size XL; run as three phases (fields and locks, inset and corners, then pattern fill and measure).** Kerf today accepts only plain numbers in its size fields, has no inset, no measure tool and no live distances. Crafters building boxes, cards and fitted parts measure on paper and calculate by hand.

## Problem

- The inspector's X, Y, W and H, Offset distance and other length fields take one number in the current unit. "2in + 5mm" or "half of this" cannot be typed.
- Offset (now spec 21's live Offset effect, built on `geometry::offset(rings, distance, round)`) has round or sharp corners only and no explicit inset mode.
- Print Then Cut shapes print a flat colour; there is no way to fill a shape with an image or a repeating pattern.
- There is no way to measure the distance between two points, and moving a shape shows no distances to its neighbours.
- There is no lock on aspect, position or layer, so a background card is easy to nudge by accident.

## Goal

### Expression fields everywhere

- `src/expr.rs` parses and evaluates length expressions: numbers, `+ - * /`, parentheses, and units `in`, `"`, `ft`, `mm`, `cm`, `m`, `pt`. A bare number takes the field's display unit. Mixed units are fine: `2in + 5mm`, `(12 - 0.5) / 3`, `30cm - 2 * 1in`.
- A leading `*` or `/` applies to the current value: `*2` doubles, `/3` divides. `=` restarts from scratch.
- Every length input in the app is one widget, `units::length_field`, which uses `expr.rs`, shows the evaluated result in the display unit on Enter or blur, shows invalid input in red with the reason in its tooltip, and keeps the old value. Angles (rotation) and plain numbers (counts, percentages) use the same parser without units.
- A scan test, like the existing units scan in `units.rs`, fails if any file other than `units.rs` builds a `DragValue` or `TextEdit` for a length, so a new field cannot skip expressions.
- With several shapes selected, an expression with a leading operator applies to each shape's own value (`*2` doubles each width).

### Inset and corner styles

- spec 21's Offset effect gains **Direction**: Outset (default) or Inset, and the distance stays positive in the UI.
- **Corners**: Round, Miter (with a limit, default 4) or Bevel. Extend `geometry::offset` to take a `Join` enum instead of a bool. Use i_overlay's own outline offset and join styles if version 9 has them (check first); otherwise add miter and bevel joins to the existing Minkowski band.
- Inset pieces that vanish (inset larger than half the narrowest part) are dropped, and the panel says "Some parts are too thin for this inset". An inset that removes everything leaves the effect in place, disabled, with that message.

### Pattern fill for Print Then Cut

- A Print Then Cut shape's fill becomes `Fill::Solid(Color32)` or `Fill::Pattern { asset: AssetId, mode: Tile | Fit | Fill | Stretch, scale, rotation_deg, offset_in }` (`#[serde(default)]` to Solid). Assets come from spec 28's store.
- The colour swatch's picker gains a **Pattern** tab: bundled patterns and **Upload image**. Bundled patterns are generated by code (stripes, dots, checks, gingham, chevrons, stars) in a small set of colourways, so there is no artwork licence to track.
- The canvas draws the pattern as a textured mesh clipped to the shape (triangulated with `earcutr`, UVs from the pattern transform). The print image for Make is rasterised with `tiny-skia`'s `Pattern` shader clipped to the shape path, at 300 dpi.
- Handles inside the selected shape move, scale and rotate the pattern without moving the shape (a small "Edit pattern" toggle in the panel).

### Measure tool and live distances

- **Measure** on the tool rail (key M, `Icon::Measure`, a new 1.5 px line icon). Drag from one point to another; the start and end snap to nodes, edges, centres and the mat using `snap.rs`. A label shows the distance, the horizontal and vertical components and the angle, in the current units. Shift constrains to 45 degree steps. The measurement stays until Escape or the next drag, and Cmd+C copies its text.
- **Live distances while dragging**: moving or resizing shows the change from the start (`dx, dy`, or the new width and height) beside the pointer. Holding Option (Alt) with a shape selected and the pointer over another shows red distance lines from the selection's edges to that shape's edges, as Figma does.

### Locks

- **Lock aspect**: a chain toggle between W and H in the inspector, stored per shape as `Shape.lock_aspect: bool`. When on, typing W changes H in proportion and side handles scale both. Shift still inverts it during a drag.
- **Lock position**: `Shape.lock_position: bool`. The shape cannot be moved, resized, rotated or flipped (handles hidden, nudges ignored, Align skips it with a tooltip saying so), but it can still be selected and recoloured, its operation changed, and its text edited.
- **Lock layer**: `Shape.locked: bool`, the lock icon on each Layers row (`Icon::Lock`/`Icon::Unlock` already exist). A locked layer cannot be selected on the canvas, by click or marquee, and is skipped by Select All; it can still be selected from Layers. Locking a parent row locks its whole link, container or instance.
- Every lock change is one undo step. A project saved before this spec loads with nothing locked.

## Files

- **Owns.** `src/expr.rs` (new: parser and evaluator; pure), `src/patterns.rs` (new: generated patterns and the fill transform; pure), `src/measure.rs` (new: measurement and distance-line geometry; pure), `src/ui/measure_tool.rs` (new), `src/ui/pattern_panel.rs` (new), `src/ui/tests_spec34.rs` (new).
- **Shared edits.** `src/units.rs` (`length_field`, the scan test), `src/geometry.rs` (`Join`), spec 21's Offset effect (direction, joins), `src/design.rs` (`Fill`, lock fields, literals), `src/ui/op_style.rs` (pattern mesh), `src/ui/inspector.rs` (chain toggle, position lock), `src/ui/layers_panel.rs` (lock icon), `src/ui/canvas.rs` and `src/ui/selection.rs` (respect locks, live distances; keep small), `src/ui/chrome.rs` (rail item, through spec 23), `src/bridge.rs` or the Print Then Cut print path (pattern raster), `src/ui/icons.rs` (Measure).
