## Evidence by finding

### AUDIT-001: fixed by autosave, by design

The prompt the audit asked for does not exist, and that was a deliberate change. Spec 33 replaced "confirm before discard" with autosave: `src/ui/persistence.rs:1-3` says "nothing asks before leaving it, since its autosave keeps the work".

* Dirty state: `Document::has_unsaved_changes` at `src/ui/persistence.rs:31-33` compares the design and title with `Saved`.
* Quit and close request: `persistence_dialogs` at `src/ui/persistence.rs:38-40` calls `quit`, and `on_exit` at `src/ui/mod.rs:784-787` does too. `quit` flushes every tab (`src/ui/autosave.rs:259-265`).
* Tab close flushes before dropping (`src/ui/tabs.rs:170-175`). A saved project's next open offers "Restore or Discard" (spec 33 line 37).
* Test: `quitting_asks_nothing_and_the_next_launch_reopens_the_tabs`, `src/ui/tests_spec33.rs:307`.
* Gap: see NEW-1. The guarantee holds for saved projects but not for a never-saved tab that is closed.

## New finding

### NEW-1: a closed never-saved tab keeps an autosave that nothing can reach

**Severity:** Medium. **Confidence:** High from code, not exercised in the GUI.

Cmd+W on a tab whose design was never saved flushes an autosave to `<projects>/autosave/<id>.json` (`src/ui/tabs.rs:170-175`, `src/store/mod.rs:66-68`) and then drops the document. No project file exists, so Home does not list it (`project::list` reads `*.json` in the projects folder only, `src/project.rs:275-290`). Crash recovery reads only the tabs named in `session.json` (`src/store/session.rs:50-63`), and a clean quit restores only open tabs (`src/ui/autosave.rs:270-`). Nothing enumerates `autosave/`. Spec 33's rule ("the next open of that project offers Restore") needs a project to open, and this one has none.

The user's view: they drew something, pressed Cmd+W by habit, and it is gone with no prompt. This is the same loss AUDIT-001 described, in the one place autosave does not cover.

## Ranked open items

Ranking is by what a user would hit or notice first. Only item 1 is a real risk; the rest are cheap hygiene. Items 6 and 7 are not worth doing unless the stated trigger happens.

### 1. Keep closed unsaved work reachable (NEW-1)

Data safety. Size S. Make Cmd+W on a dirty never-saved tab recoverable. Home lists autosave-only entries (those in `autosave/` with no project file and not open in a tab) as cards marked "Unsaved", with Open and Delete, newest first, so the existing Restore or Discard offer on open applies unchanged. `store` gains a `list_orphan_autosaves(dir, open_ids)` that skips ids with a project file or an open tab, and `project::list`'s caller merges them. Prune an orphan after 30 days or when the user deletes it, and never while its id is open. Acceptance: a kittest edits a new tab, closes it, finds the card on Home, opens it and sees the shapes; closing a clean blank tab leaves no card; a corrupt autosave shows as unreadable rather than disappearing (follow `Entry::Unreadable`).

### 2. Put the heavy-design timing in front of someone (AUDIT-015 residual)

Performance. Size S then M. First, add a non-ignored job to CI that builds release and runs `tests_spec38`'s gate and the 200-shape idle test, printing the table, with ceilings set from one recorded run on the CI runner, so a regression fails instead of waiting for a manual run. Second, only if the numbers show the per-frame whole-design clone (`src/ui/mod.rs:860-868`) in the top costs, replace the `before` clone with a revision counter plus a copy-on-first-write snapshot kept by `History`. Do not change the clone speculatively: the cache already absorbs most of the cost, and the benchmark exists to settle it. Acceptance: CI shows the table on every push, a deliberate 2x slowdown fails it, and the median drag frame on the 150-object scenario is recorded in the spec.

### 3. Warn when a chosen font is not installed (AUDIT-008 residual)

Correctness a user would notice. Size S. When a design has text in a `FontRef::System` family that the settled catalogue does not hold, show a notice on Prepare listing the families and saying "cuts in Inter", with a "Pick a font" action that selects the first affected text. The model already knows: `FontCatalogue::families` and `face` (`src/system_fonts.rs:261-265`) answer it once the scan is ready, and `settle_for` runs before Make. Add the check to Prepare's notice list beside the existing "too large for this mat" notice, and mark the text in Layers with a small warning glyph. Acceptance: a kittest with a fixture catalogue lacking "Zapfino" shows the notice, and picking an installed family clears it.

### 4. Finish the module map and the rename leftovers (AUDIT-016 residual)

Orientation. Size S. Add the nine missing modules to the README table, driven by a test that fails when a `mod` in `src/main.rs` has no row (the audit's own validation), and rename `ODS_LOG` and `ODS_LOG_FILE` to `KERF_LOG` and `KERF_LOG_FILE`, still honouring the old names the way `project::DIR_ENV` honours `ODS_PROJECTS_DIR` (`src/project.rs:46-49`). Acceptance: the test passes, `rg ODS_ src README.md` finds only the documented fallbacks.

### 5. Delete the dead closed-outline branch and split the inline tests (AUDIT-024, 022 residuals)

Maintainability. Size S. Delete the closed branch of `paint_outline` and `triangulate` (`src/ui/canvas.rs:965-998`), leaving the open polyline path. Then move the `mod tests` block out of `src/ui/mod.rs` into `src/ui/tests_core.rs`, leaving `mod.rs` at its production 890 lines, and replace the wall-clock sleeps in `tests_spec28.rs` and `tests_spec30.rs` with the workers' completion signal. No behaviour change, so the existing suite is the acceptance test: it passes unchanged with identical snapshot baselines.

### 6. Decide the licence position and say it once (AUDIT-004, 012)

Housekeeping, only if publishing is ever on the table. Size S now, L if publishing. Today `README.md:3` says "open-source" while `deny.toml` says the project is for personal use and unpublished, and the tree still carries Design Space icons and screenshots. Fix the sentence so it says what is true ("a personal-use clone"). If publishing becomes a goal, the original spec 22 item 6 stands as written: replace the 22 compiled-in icons, delete `assets/ds/shapes/previews` and the 94 unused icons, decide on the screenshots and `docs/native-supporting`, add `LICENSE`.

### 7. Convert the remaining write-only snapshots (AUDIT-011 residual)

Test quality. Size M. Go through the 73 `save_snapshot` calls and for each either switch to `assert_snapshot`, add a pixel assertion, or delete it when it guards nothing. Keep the few that exist for the human to look at, renamed `look_at_snapshot` so the intent is plain. Do this opportunistically when a spec touches the same test file, not as its own spec. Acceptance: no `save_snapshot` call remains in a test that has no other assertion about what it drew.
